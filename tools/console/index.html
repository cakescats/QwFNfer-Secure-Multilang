Эта машина

Ярус — рассчитан для выбранной модели на этой машине

Сервер работает с настройками из баннера. Чтобы сменить модель или настройки, остановите его.

Автонастройка измеряет машину и подбирает все флаги по результату: скорость чтения диска, затем план (какую точность KV вмещает GPU, ярусы, batch, где хранить состояние внимания, какой ярус RAM позволяет память), затем запускает сервер, проверяет его на коротком чате и длинном документе и подбирает число потоков CPU живым прогоном. Около четырёх минут; результат сохраняется для этой модели, а карточка яруса показывает измеренную скорость.
